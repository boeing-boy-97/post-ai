# Quickstart Guide — PostWave AI

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/bha92ubar1513-collab/ai-automation.git AI-Social-Media-Scheduler
cd AI-Social-Media-Scheduler

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
```

### 2. Build Frontend & Start Server
```bash
# In the frontend directory, build production bundle
npm run build

# Start backend server
cd ../backend
npm run build
npm start
```

Open `http://localhost:4000` to view the live dashboard.
